الإجراءات السريعة

اختصارات لأهم صفحات النظام
إدخال إنتاج جديد تسجيل إنتاج العامل حسب التاريخ والشفت والمنتجات. إدخال تقييم مشرف تقييم العامل حسب الجودة والنظافة والانضباط وبقية العناصر. استعراض سجل الإنتاج البحث حسب التاريخ والعامل وعرض الإنتاج المدخل. إدارة العمال عرض العمال النشطين وإضافة عمال جدد. إدارة المنتجات إضافة المنتجات وتحديد التصنيف والمكينة والهدر القياسي. إدارة المكائن إضافة المكائن وتصنيفها حسب نوع المكينة.

ملاحظات النظام

حسب الصلاحيات
الإنتاج اليومي يمكن إدخال الإنتاج اليومي وربطه بالعامل والمنتج والمكينة.
صلاحيات المشرف المشرف لا يستطيع تعديل أو حذف بيانات الإنتاج للأيام السابقة.
المنتجات والمكائن تعديل أو حذف المنتجات والمكائن متاح لمدير النظام فقط.
